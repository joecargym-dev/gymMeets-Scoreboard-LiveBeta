# GymMeets Scoreboards

Professional scoring displays for ProScore/NexusDB.

## Project Vision

GymMeets Scoreboards is a modern display system designed to enhance gymnastics competitions by providing professional, customizable scoreboards and event displays.

The project is designed around:

- Vault
- Uneven Bars
- Balance Beam
- Floor Exercise
- 4x1 Displays
- Shared Branding
- Live Control Panels
- Spectator Displays (future)

## Athlete birthdate handling

An athlete's birthdate may be read transiently from the customer's local
ProScore database only when technically necessary to calculate the
meet-defined age division. The birthdate is not displayed, stored, cached,
logged, transmitted, included in status files, sent to GymMeets servers, or
exposed to sponsors or analytics. After the local calculation, only the
resulting division label continues through the display system.

## Goal

Provide modern, customizable gymnastics scoring displays that are easy to deploy, visually appealing, and work seamlessly with ProScore and NexusDB.
